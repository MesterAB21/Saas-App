# 🚀 EduAi – AI Voice Learning Companion

> Turn learning into a real-time conversation with AI voice tutors.

EduAi is a **full-stack SaaS platform** where users create and interact with **AI companions** that teach topics through natural voice conversations.

---


## 🌐 Live App
👉 https://eduaiapp-phi.vercel.app
---

## 💡 Problem

Learning today is mostly **passive** (videos, courses):

- No real-time interaction  
- Low engagement  
- No personalization  

---

## ⚙️ Core Features

- 🎙️ **AI Voice Companions**  
  Real-time interactive conversations with AI tutors  

- 🌍 **Public Companion Library**  
  Explore and use companions created by others  

- ✍️ **Custom Companion Creation**  
  Create your own learning agents (topic-based)  

- 📊 **Session Tracking**  
  Save and revisit past conversations  

- 💳 **Subscription System**  
  Plan-based limits (Basic / Core / Unlimited)  

- 🔐 **Authentication & Access Control**  
  Secure user system with feature restrictions  

---

## 🧠 How It Works

1. User signs in  
2. Creates or selects a companion  
3. Starts a voice conversation  
4. AI explains, asks, and adapts  
5. Session is saved for later  

---

## 🛠️ Tech Stack

- **Frontend:** Next.js  
- **Backend & DB:** Supabase (PostgreSQL)  
- **Auth & Subscriptions:** Clerk  
- **AI Voice:** Vapi  
- **Styling:** Tailwind CSS  

---

## 🏗️ Key Functionalities

- `createCompanion()` → create AI learning agents  
- `startSession()` → launch voice interaction  
- `trackSession()` → store history  
- `subscriptionCheck()` → enforce plan limits
